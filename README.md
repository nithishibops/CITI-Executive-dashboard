# Citi Executive Analytics Dashboard

GitHub Pages / Vercel-ready one-page dashboard built from the supplied Citi workbook.

## GitHub Pages
Upload all files/folders to the repository root, then:
Settings → Pages → Deploy from a branch → main → /(root).

## Vercel
Import the GitHub repository into Vercel.
Framework preset: Other.
No build command is required.

Plotly is bundled locally, so the charts do not depend on a CDN.
